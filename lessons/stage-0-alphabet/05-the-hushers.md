# Lesson 5 — The Hushers (and Ц)

**Stage 0 · Alphabet** · ⏱ 50–60 min · New letters: **Ж Ш Щ Ч Ц**
Already known: 26 letters → after today **31 of 33**.

## 🎯 Goals

- Learn the five "hushing and hissing" letters **Ж Ш Щ Ч Ц**;
- know which are **always hard** and which are **always soft**;
- read **здра́вствуйте, до свида́ния, пожа́луйста, хорошо́, что?, как дела́?** and introduce yourself: **Меня́ зову́т…**;
- learn the core question words.

## 2. The five new letters

| Letter | Sound | English cue | Notes |
|:---:|:---:|---|---|
| **Ж ж** | *zh* | **s** in *mea**s**ure*, **g** in *gara**g**e* (French *j*) | Looks like a **beetle** — **жук** (*zhook*) is Russian for "beetle". |
| **Ш ш** | *sh* | **sh** in *shoe* — but curl the tongue tip **slightly back** and keep it a bit "thicker" | Looks like three little legs. |
| **Щ щ** | *shch* | a **long, soft "sh"** — like **sh-ch** in *fre**sh ch**eese* said as one smooth sound | **Ш with a tail.** Longer and "lighter" than Ш. |
| **Ч ч** | *ch* | **ch** in *ch**ee**se* — but a **soft** one | Looks like a **4** → "ch". |
| **Ц ц** | *ts* | **ts** in *ca**ts*** | **Ц with a tail** — like Ш with a tail, but one stroke fewer. |

> ⚠️ **Don't mix them up:** **Ш** (*sh*) — **Щ** (*shch*) — **Ц** (*ts*). The tail on Щ and Ц is the clue: Щ = three legs + tail, Ц = two legs + tail.

### Always hard, always soft — the rule that explains a lot

| Always **hard** | Always **soft** |
|:---:|:---:|
| **Ж  Ш  Ц** | **Ч  Щ  Й** |

- You can't soften **ж, ш, ц** — they stay hard even before **и**/**е**: **маши́на** sounds like *ma-SHIH-na*, **жена́** like *zhih-NA*, **цирк** like *tsihrk*. (The spelling is **и**, the sound is **ы**.)
- **ч, щ, й** are always soft — so you never need a soft sign to make them soft.

> 🧠 **Spelling preview (you'll use this in grammar):** after **ж, ш, ч, щ** Russians write **и, а, у** — never **ы, я, ю**. That's why you see **чай**, **часы́**, **шко́ла**, **борщ**, **щи**, **ещё** and *never* "чя", "шы", "щю". It's the first and most useful Russian spelling rule.

## 4. New words

### Greetings & politeness — *use these from now on*

| Russian | Respelling | English |
|---|---|---|
| **Здра́вствуйте!** | *ZDRAST-vooy-tye* | Hello! (formal / to several people) — the first **в** is silent! |
| **До свида́ния!** | *da svee-DA-nee-ya* | Goodbye! (formal) |
| **Пожа́луйста** | *pa-ZHA-loo-sta* | please; you're welcome |
| **Хорошо́** | *kha-ra-SHO* | good; well; OK |
| **Отли́чно** | *at-LEECH-na* | excellent |
| **Пло́хо** | *PLO-kha* | bad; badly |
| **Ничего́** | *nee-chee-VO* | not bad / it's OK / never mind / nothing |
| **Как дела́?** | *kak dee-LA* | How are things? |
| **А у тебя́?** | *a oo tee-BYA* | And you? (informal) |
| **А у вас?** | *a oo VAS* | And you? (formal) |
| **Как вас зову́т?** | *kak vas za-VOOT* | What's your name? (formal) |
| **Как тебя́ зову́т?** | *kak tee-BYA za-VOOT* | What's your name? (informal) |
| **Меня́ зову́т…** | *mee-NYA za-VOOT* | My name is… (literally "they call me…") |

### Question words — *learn all seven*

| Russian | Respelling | English |
|---|---|---|
| **кто** | *kto* | who |
| **что** | *shto* ⚠️ | what |
| **где** | *gdye* | where (at what place) |
| **куда́** | *koo-DA* | where to |
| **когда́** | *kag-DA* | when |
| **как** | *kak* | how |
| **почему́** | *pa-chee-MOO* | why |

> ⚠️ **что** is written *chto* but pronounced ***shto***. It's the most famous exception in Russian. Same for **ничего́** (the **г** sounds like **в**: *nee-chee-VO*).

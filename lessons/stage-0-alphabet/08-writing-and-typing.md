# Lesson 8 — Writing, Typing & Your Name in Cyrillic

**Stage 0 · Alphabet** · ⏱ 45–60 min (plus daily handwriting practice) · No new letters

## 🎯 Goals

- Know the alphabet **in order** (so you can use a dictionary);
- write Russian by hand — print letters first, then the **cursive** forms that look different;
- set up a **Russian keyboard** and type;
- write **your own name** and other English names in Cyrillic;
- read famous Russian names and words.

---

## 1. Review (3 minutes)

Say each aloud: **Здра́вствуйте! Меня́ зову́т … Я студе́нт(ка). Я не понима́ю. Повтори́те, пожа́луйста.** Then write one of them from memory.

## 2. The alphabet in order

Learn this order — Russian dictionaries and lists use it. Say it aloud a few times.

| | | | | | | | | | | |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| **А а** | **Б б** | **В в** | **Г г** | **Д д** | **Е е** | **Ё ё** | **Ж ж** | **З з** | **И и** | **Й й** |
| **К к** | **Л л** | **М м** | **Н н** | **О о** | **П п** | **Р р** | **С с** | **Т т** | **У у** | **Ф ф** |
| **Х х** | **Ц ц** | **Ч ч** | **Ш ш** | **Щ щ** | **Ъ ъ** | **Ы ы** | **Ь ь** | **Э э** | **Ю ю** | **Я я** |

That's 33 letters: **10 vowels** (а э ы о у я е и ё ю), **21 consonants**, and **2 signs** (ь ъ). *(Й counts among the consonants.)*

> 📖 *Letter names* (used when spelling a word aloud) are in [`reference/alphabet.md`](../../reference/alphabet.md).

## 3. Handwriting

### Two systems
Russians use **print** letters (in books/screens) and **cursive** (in handwriting). Cursive isn't just joined-up print: **several letters change shape**. For *typing* and *reading texts*, print is all you need. For *reading handwriting* (notes, signs, notes from friends) and for *writing by hand*, learn cursive too — but don't let it slow you down: put 10 minutes a day on handwriting and let it grow.

### Handwriting: the traps
These printed letters look **very different** in handwriting — that's the part to practise:

| Printed | In cursive it looks like… | Tip |
|:---:|---|---|
| **т** | a small **m** | Many writers put a **bar above** it: m̅ |
| **и** | a small **u** | |
| **п** | a small **n** | Sometimes with a bar above |
| **д** | a **g**-like loop | Descends below the line |
| **л** | an upside-down **V** with a small hook on the left | |
| **ш** | like **ɯ** — three humps | Many writers put a **bar below** it |
| **б** | like a **6** or Greek **δ** | |
| **у** | like an English **y** | |

> ⚠️ **The famous problem:** in cursive, the letters **ш, т, и, п, м, л** can blur into a row of "u", "m" and "n" shapes. That's why many Russians add a **bar above т** and a **bar below ш** — so "тишина́" ("silence") is readable.

> 🖼 **See it, don't just read about it:** search for *"Russian cursive alphabet chart"* or *"ру́сские про́писи"* (Russian copybooks), print one and trace it. Learning cursive from a picture of a real chart is much easier than from a description.

### A 10-minute daily routine
1. Write the 33 letters in print, **saying each sound**.
2. Write 5 letters in cursive (do a different 5 each day).
3. Copy 5 words from your current lesson, in both print and cursive.
4. Write one sentence from memory.

## 4. Typing in Russian

### Set up a Russian keyboard
* **Windows 10/11:** Settings → Time & language → Language & region → Add a language → **Ру́сский (Russian)**. Switch layout with **Win + Space** (or **Alt + Shift**).
* **macOS:** System Settings → Keyboard → Input Sources → **+** → Russian. Switch with **Ctrl + Space** or the 🌐 key.
* **iPhone / Android:** Settings → Keyboards / Languages → add **Russian**. Hold **е** to get **ё**.
* **Linux:** `setxkbmap ru` or your desktop's keyboard settings.

### Which layout?
* **Standard (ЙЦУКЕН):** what Russians use. Letters are in fixed places: the top row starts **й ц у к е н г ш щ з х ъ**. Worth learning in the long run (and you can always put stickers on your keys).
* **Phonetic / mnemonic:** letters sit on the Latin key that sounds similar (**A → а, B → б, V → в…**). Faster to start. Look for options named *Phonetic* or *Mnemonic* in your OS's Russian layouts.

Pick one and stick to it for the first month.

### Typing tips
* **Ё** — on standard layouts it's the key at the **top left** (the one with `` ` `` on English keyboards). Russians often type **е** instead of **ё**; for learning, use **ё**.
* **Stress marks** — you don't type them in normal writing. For notes, copy the accented word from a dictionary (Wiktionary shows stress).
* **Practice:** retype the alphabet and the words from Lessons 1–7; try typing games or typing sites that offer a Russian layout.

## 5. Your name in Cyrillic

There is no single official rule for English names, but the conventions below are what Russians use.

| English sound/letter | Cyrillic | Example |
|:---:|:---:|---|
| **j** (*Jack*) | **дж** | Джек, Джон, Дже́ссика |
| **ch** | **ч** | Ча́рли |
| **sh** | **ш** | Шон |
| **w** | **в** or **у** | Ва́лтер · Уи́льям |
| **h** | **х** or **г** | Хло́я · Ге́нри |
| **y** at the start (*Yan*) | **й** or **я/ю** | Йен · Ю́джин |
| **short e** after a consonant | **э** | Дэ́вид · Сэм · Мэ́ри |
| **long i** (*Mike*) | **ай** | Майк, Майкл |
| **ay** (*Kate*) | **эй** | Кейт |
| **x** | **кс** | А́лекс |

Some examples:

| English | Russian |
|---|---|
| James | Джеймс |
| John | Джон |
| Michael | Майкл |
| David | Дэ́вид |
| Sarah | Са́ра |
| Emily | Э́мили |
| Jessica | Дже́ссика |
| Alex | А́лекс |
| Emma | Э́мма |
| Kate | Кейт |
| Jack | Джек |
| William | Уи́льям |
| Henry | Ге́нри |
| Mary | Мэ́ри |

> **Write your name** — in print and cursive — and put it at the top of your notebook. This is your Russian "business card".

## 6. Practice

### Exercise 1 — Alphabet order
Write the alphabet **from memory** in order (print). Check yourself against section 2.

### Exercise 2 — Dictionary game
Put these in alphabetical (Russian) order:

**кни́га · ру́чка · дом · ма́ма · апте́ка · шкаф · окно́ · зонт**

*(окно́ = window, зонт = umbrella, both easy to read!)*

### Exercise 3 — Your name
Write your first name in Cyrillic, print and cursive. Then write a friend's or family member's name.

### Exercise 4 — Latin → Cyrillic
Write in Cyrillic: **Thomas · Jennifer · Henry · William · Lucy · Ben · Chris**

### Exercise 5 — Cyrillic → Latin
These are English names written in Russian. Who are they? **Дэ́вид · Э́мма · Сэм · Кейт · Майкл · Дже́ннифер**

### Exercise 6 — Famous Russian words
Read aloud (with the stress marks), then match with the meaning:

**1.** Достое́вский **2.** Толсто́й **3.** Пу́шкин **4.** Че́хов **5.** Чайко́вский **6.** Гага́рин **7.** Кремль **8.** спу́тник **9.** матрёшка **10.** во́дка

**a.** the first man in space **b.** *War and Peace* author **c.** *Crime and Punishment* author **d.** nesting doll **e.** a famous poet **f.** the "Swan Lake" composer **g.** satellite **h.** the Moscow fortress **i.** playwright (*The Cherry Orchard*) **j.** a well-known drink

### Exercise 7 — Type it
On your keyboard, type: **Я изуча́ю ру́сский язы́к.** *(I'm studying Russian.)* — then type your name.
